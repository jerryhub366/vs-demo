# vs-demo

## 首个 demo 方向与定位

1. 明确“首个 demo 只服务一种人群”的原则（先不追求通吃）。
2. 选择方向：**A. AI 赋能个人增长/效率（2C 付费快）**。
3. 一句话定位：
   * 我帮助**一人公司/自由职业者**用**AI + 产品增长与系统化经验**解决**内容生产与运营效率低**问题，交付**每周稳定产出 5–8 条高质量内容并节省 10 小时以上**的可量化成果。
4. 最小可交付“产品包”名称：**AI 效率增长启动包**。
5. 用户画像 + 核心痛点 + 可衡量成果：
   * 用户画像：30–40 岁一人公司/自由职业者，有稳定专业能力但缺系统化内容生产流程。
   * 核心痛点：内容产出依赖灵感，写作与发布流程零散，导致增长缓慢。
   * 可衡量成果：两周内搭建可复用的内容生产流程，单周产出 5–8 条内容并减少 10+ 小时手工整理时间。
